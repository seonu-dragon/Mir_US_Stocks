## 2. 매도 주체 대조용 원천(참고)

DART 5%룰·임원 소유 보고(`data/kr_ownership.*`, OpenDART)는 이미 미르가 합법적으로 쓴다. 이 데이터의 `reason` 필드에 '장외매도', '시간외대량매매' 같은 사유가 적힐 때가 있다. 하지만 블록딜 체결 목록 자체(A·B)를 가져올 수 없으면 '공시 확인 / 미공개'로 대조할 대상이 없다.

## 3. 약관 인용(짧게)

### 3-1. KRX 법적고지 (KIND 하단 '법적고지' 링크)
URL: http://info.krx.co.kr/contents/KRX/06/06070200/KRX06070200.jsp

> "이용자는 한국거래소가 제공하는 서비스를 무단으로 전재하거나 한국거래소의 사전 동의없이 복제, 전송, 출판, 배포, 방송 기타 방법에 의하여 이용하거나 제3자에게 무단으로 배포 할 수 없습니다."

KIND 하단에는 KRX 법적고지 · 이용자유의사항이 링크되어 있고, KIND 전용 약관은 따로 없다. 미르는 데이터를 커밋해 GitHub Pages로 공개 서빙하므로 이 조항의 '복제·전송·배포'에 그대로 해당한다.

### 3-2. KRX 정보데이터시스템 홈페이지 이용약관 (2026-08-29 시행)
URL: https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd

> 제10조(금지행위) "② 자동화 수단을 이용하여 정보를 무단 수집·복제·배포하는 행위"
> 제12조 "② 이용자는 당 사이트의 정보를 거래소의 사전 허락 없이 복사·복제·배포·전송·공중송신하여서는 아니 됩니다."

GitHub Actions 빌더로 수집하는 것은 '자동화 수단'에 해당한다. 공개 페이지로 내보내는 것은 '배포·공중송신'에 해당한다. 둘 다 금지다.

URL: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp

> 제6조 "② API 이용자는 API 서비스를 비상업적인 목적으로만 이용할 수 있으며…"
> 제11조 "② API 이용자는 한국거래소로부터 제공받은 정보를 제3자에게 제공할 수 없다."

대량매매 API가 없어서 이번 기능과는 무관하다. 다만 같은 조항이 다른 KRX 연동에도 적용될 수 있어 아래 4에 적었다.

## 4. 판단

- **보류(no-go).** 블록딜 체결 목록을 주는 공식 원천은 A(KIND)와 B(정보데이터시스템)뿐이다. 둘 다 KRX 약관이 사전 동의 없는 복제·배포를 금지하고, B는 자동 수집도 명시적으로 금지한다. C·D·E에는 해당 데이터가 없다.
- 사실 수치(수량·비율)에는 저작권이 약할 수 있다. 그래도 날마다 체계적으로 수집해 공개하면 데이터베이스제작자 권리(저작권법 제93조)와 약관 위반 문제가 생긴다. 미르의 원칙(약관 준수, 금지된 곳은 스크래핑하지 않음)상 진행하지 않는다.
- 이번 작업에서 코드 · 데이터 · 워크플로우 · FEATURE_DATA는 바꾸지 않았다.

## 5. 다시 열려면

1. KRX에 서면 허락을 받는다(krxdata@krx.co.kr, Data Marketplace '데이터 분배'). 허락 범위(자동 수집, 공개 웹 게시, 출처 표기 방식)를 문서로 받는다. 허락받으면 A(KIND 대량매매내역 HTML, 시장별 하루 1건)가 가장 단순한 경로다. 필드는 체결일자 · 종목 · 종목거래량 · 대량매매수량 · 비율 · 시간대/유형이다. 가격·금액·주체는 없으므로 '금액'은 종가×수량 **추정**으로만 표시해야 한다.
2. 허락 없이 할 수 있는 대체안: OpenDART 5%룰·임원 소유 보고의 사유 문구('시간외대량매매'·'장외매도' 등)만으로 **'공시로 확인된 대량 처분'** 목록을 만든다. 거래소 체결 목록이 아니고 보고 지연(최대 5영업일)이 있으므로, 블록딜 피드라고 부르지 말고 별도 기능으로 기획한다.

## 6. 부수 발견(이번 범위 밖, 확인 권장)

- 3-2 제10조②(자동 수집 금지)와 제12조②(배포 금지)는 2026-08-29 시행 약관이다. data.krx.co.kr을 읽는 기존 빌더(`build_kr_short_interest.py`·`build_kr_short_volume.py`·`build_kr_etf_holdings.py`)에도 같은 조항이 적용될 수 있다. 메인테이너가 따로 검토할 것.
- 3-3 제11조②(제3자 제공 금지): 현재 OPEN API 인증키를 쓰는 빌더는 찾지 못했다. 나중에 도입하면 같은 문제가 생긴다.
